## إعادة تصميم قسم "الثقة والتوثيق" ليطابق المرجع HTML

### الشكل الجديد (عمودين على الديسكتوب)

```text
┌─────────────────────────┬─────────────────────────┐
│  [▶ فيديو الحملة 16:9]   │  📜 التوكيل الشرعي       │
│                         │  ───────────────────    │
│  [▶ أرشيف 16:7]          │  📸 توثيق ميداني حقيقي   │
│                         │  ───────────────────    │
│  [thumb][thumb][thumb]  │  🌍 سابقة أعوام موثّقة   │
│                         │  ───────────────────    │
│                         │  [بطاقة CTA خضراء]       │
└─────────────────────────┴─────────────────────────┘
```

### التغييرات

**1. `src/components/site/TrustSection.tsx` — إعادة كتابة كاملة:**
- إزالة شريط الـ badges العلوي (الإحصائيات الأربع) — غير موجود في المرجع
- شبكة `md:grid-cols-2` بعمودين: 
  - **عمود الفيديوهات** (يسار في RTL): فيديو رئيسي 16:9 + فيديو أرشيف 16:7 + شبكة 3 صور مصغّرة
  - **عمود البطاقات** (يمين في RTL): 3 بطاقات (التوكيل الشرعي / توثيق ميداني / سابقة أعوام) كل منها أيقونة في مربع `bg-green-pale` + عنوان + وصف
- **بطاقة CTA رابعة** خضراء (`bg-green`) أسفل البطاقات تحوي:
  - نص بخط Amiri: "أضحيتك أجران — منك النُّسُك ومنّا الوصول"
  - زر "وكِّل أضحيتك الآن" يمرّر إلى `#checkout`
- مكوّن داخلي `VideoCard` مع أيقونة Play دائرية في المنتصف وlabel أسفل-يمين
- استخدام صور Unsplash نفسها الواردة في المرجع
- خلفية القسم: `bg-cream-dark/60` (متناسقة مع باقي الأقسام)

**2. الأيقونات:** استبدال الأيقونات الحالية بـ `ScrollText` (📜) و `Camera` (📸) و `Globe2` (🌍) من lucide-react لمطابقة المعنى.

**3. لا حاجة لتعديل ملفات الترجمة** — جميع المفاتيح المستخدمة (`trust.eyebrow`, `trust.title`, `trust.subtitle`, `trust.items`, `header.cta`) موجودة بالفعل. سأضيف فقط مفتاحين اختياريين بـ `defaultValue` داخل الكود لـ labels الفيديو.

### القيود
- لا تغيير في `Index.tsx` أو منطق Checkout
- لا تغيير في schema قاعدة البيانات
- الحفاظ على الـ semantic tokens (`bg-green`, `text-brown`, `bg-cream-dark` ...)
