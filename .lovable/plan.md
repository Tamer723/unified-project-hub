# تحسين عرض المسار الثالث في لوحة الطلبات

## التغييرات في `src/pages/admin/Orders.tsx`

### 1) دوال مساعدة جديدة
استخدام ملفات الترجمة الموجودة (`track3.countries.*`, `track3.animals.*`) لتحويل الرموز إلى أسماء كاملة + خريطة Emoji للأعلام:

```ts
const COUNTRY_FLAGS: Record<string, string> = {
  JM: "🇵🇸", WB: "🇵🇸", LB: "🇱🇧", SY: "🇸🇾",
  SD: "🇸🇩", YE: "🇾🇪", BD: "🇧🇩",
};
const ANIMAL_EMOJI: Record<string, string> = { sheep: "🐏", cow_share: "🐄" };
```

### 2) عمود "المسار" — شارات ملوّنة
بدل النص الرمادي الصغير، يظهر للمسار الثالث صفّ شارتين تحت العنوان:
- شارة الدولة: `bg-sand/40 text-brown` مع العَلَم + الاسم العربي
- شارة الحيوان: `bg-green-pale text-green` مع الإيموجي + الاسم العربي
- المساران 1 و2: تبقى كما هي (بدون شارات)

### 3) فلترَين جديدَين
بجانب فلتر الحالة الحالي:
- `Select` للدولة (كل الدول + الدول السبع)
- `Select` للحيوان (الكل + خروف + سهم بقرة)
- التطبيق على `product_price_matrix.country_code` و`animal_code` (يستثني تلقائياً المسارات 1 و2 عند الفلترة)

### 4) لوحة التفاصيل (Sheet)
استبدال صفوف "الدولة" و"الحيوان" لتعرض الأسماء الكاملة العربية مع الإيموجي بدل الرموز الخام.

### 5) تصدير CSV
- استبدال عمود `variant` بعمودين: `country_code`, `country_name`, `animal_code`, `animal_name`.
- الأسماء بالعربية لسهولة القراءة في Excel.

## الملفات المعدّلة
- `src/pages/admin/Orders.tsx` فقط

## ملاحظات
- لا تغييرات على قاعدة البيانات أو الـ hooks — البيانات مجلوبة فعلياً عبر الـjoin.
- الترجمات موجودة سلفاً في `track3.countries.*` و`track3.animals.*` فلا حاجة لتعديل ملفات i18n.
